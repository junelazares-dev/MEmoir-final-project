# MEmoir AI

Description:

MEmoir AI is a personal AI-powered diary designed to preserve memories, personal experiences, and messages for future generations. It allows registered beneficiaries to ask questions and access entries based on permissions set by the owner. It also features scheduled message releases, personal glossaries, and curated family memories.

# Instructions:

1. Clone or download the project repository.
2. Install the required dependencies.
3. Configure the application and its necessary services.
4. Run the application using the provided setup configuration.
5. Use fictional data for testing and development.

# Usage:

- Create and manage personal diary entries.
- Set access permissions for registered beneficiaries.
- Ask the AI questions about authorized memories.
- Access scheduled messages through time capsules.
- Explore People Pages, Places Pages, and the Life-Lessons Shelf.
- View AI-generated answers with entry date citations.
