# MEmoir-final-project
A personal AI diary that preserves an owner's daily entries for years and answers authorized questions about them after the owner's death.

Features

Personal diary entries with different writing modes

Policy-based access control using Prolog

Custom Legacy Policy language with parser and interpreter

AI-powered answers grounded in permitted entries with citations

Secure, append-only diary records

Project

Developed for CS 413 – Programming Languages as a final project demonstrating the application of multiple programming paradigms.
